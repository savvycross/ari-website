# Pere Arilda — Executive Virtual Assistant website

Next.js (App Router) + TypeScript + Tailwind CSS, exported as a static site.

```bash
npm install
npm run dev     # local preview at http://localhost:3000
npm run build   # static site written to /out
```

- **Text and details** live in `/data` (`site.ts`, `services.ts`, `experience.ts`, `testimonials.ts`, `faq.ts`).
- **Images** live in `/public/images`.
- Anything starting with `TODO_` is a placeholder still to be filled in. Search the project for `TODO_` to find them all.

A fuller editing guide will be added when the remaining pages are built.
